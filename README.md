# 🌿 NutriAware - Smart Nutrition Awareness Platform

> **Eat Smart. Learn Nutrition. Live Better.**

NutriAware is an AI-powered smart nutrition awareness web platform designed for students and busy eaters to make instant, health-conscious dietary choices. It incorporates computer vision AI food recognition, macro-nutrient analysis, smart healthy swaps, daily hydration tracking, nutrition quizzes, and a floating AI chatbot assistant.

## 🌟 Key Features

1. **Hero Section**: Responsive high-converting header with primary headline *"Eat Smart. Learn Nutrition. Live Better."*, subheadline, and primary *"Try AI Scanner"* CTA.
2. **AI Food Scanner Simulator Modal**:
   - Interactive meal recognition (Avocado Salad, Quinoa Bowl, Cheeseburger, Berry Parfait).
   - Animated scanline beam effect.
   - Detailed macro stats (Calories, Protein, Carbs, Fats) + NutriScore Grade + Smart Alternative Swap suggestions.
3. **Smart Features Grid (6 Core Cards)**:
   - 🤖 **AI Food Scanner**
   - 📊 **Nutrition Information**
   - 🥗 **Healthy Alternatives**
   - 🧠 **Interactive Quizzes**
   - 💧 **Water Reminders**
   - 📈 **Progress Dashboard**
4. **How It Works Timeline**: Step-by-step visual flowchart (*Search/Scan ➔ AI Recognition ➔ View Nutrition Info ➔ Choose Healthy Alternative*).
5. **Interactive Habit Tools**:
   - **Daily Nutrition Quiz**: 3-question quiz with instant answer feedback and score calculation.
   - **Water Tracker Widget**: Incremental liquid intake counter (+250ml / +500ml) with progress fill bar.
   - **Progress Analytics Dashboard**: Interactive Chart.js weekly macro distribution log.
6. **NutriAssist AI Floating Chatbot**:
   - Anchored to bottom right corner with online status indicator.
   - Sample prompt chips and interactive typing simulation.
   - Documented Node.js and Firebase backend integration binding hooks (`/* BACKEND HANDOFF HOOK */`).

## 🚀 How to Host & View Live on GitHub Pages

1. Go to **[GitHub.com](https://github.com/shreyasshinde619)** logged in as **`shreyasshinde619`**.
2. Create a public repository named **`NutriAware`**.
3. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and `.gitignore`.
4. Navigate to **Settings** ➔ **Pages**, select branch **`main`**, and click **Save**.
5. Your live link will immediately be online at:
   `https://shreyasshinde619.github.io/NutriAware/`
